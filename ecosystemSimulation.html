Simulation d'Écosystème

Architecture Logicielle Modulaire en C#

Dans le cadre de notre cours d'architecture logicielle, nous avons développé un logiciel de simulation d'écosystème conçu avec une architecture hautement modulaire en .NET. Ce projet simule les interactions complexes entre différentes espèces dans un environnement naturel évolutif.

Aperçu de la simulation :


Concept de la Simulation

La simulation modélise un écosystème complet où trois types d'entités interagissent :

  • Les moutons : Herbivores qui se nourrissent d'herbe et peuvent fuir les prédateurs
  • Les loups : Prédateurs qui chassent les moutons pour survivre
  • L'herbe : Producteur primaire qui croît naturellement et nourrit les herbivores

Architecture Modulaire

Le projet est conçu avec une séparation claire entre le moteur de simulation et l'interface graphique :

  • Moteur de simulation : Entièrement indépendant de la partie graphique, gère la logique métier
  • Interface graphique : Développée avec MonoGame, représente visuellement l'état de la simulation
  • Système d'entités : Architecture basée sur des entités modulaires avec comportements autonomes
  • Automates finis : Contrôlent les comportements complexes de chaque type d'entité

Système d'Évolution

Chaque entité possède des caractéristiques héréditaires qui évoluent au fil des générations :

  • Vitesse : Détermine la rapidité de déplacement
  • Taille : Influence les interactions et la consommation d'énergie
  • Champ de vision : Angle de perception (0° à 360°)
  • Distance de vue : Rayon de détection des autres entités
  • Mutations génétiques : Variations aléatoires lors de la reproduction

Comportements Adaptatifs

Moutons

Automate comportemental simple gérant les transitions entre :

  • Recherche de nourriture
  • Repos pour récupérer de l'énergie
  • Fuite en présence de prédateurs
  • Alimentation active

Loups

Automate plus complexe incluant :

  • Chasse active avec accélération vers les proies
  • Recherche territoriale
  • Repos et récupération
  • Stratégies de prédation adaptatives

Herbe

Croissance automatique et régénération énergétique progressive.

Optimisations Techniques

  • Système de chunks : Optimisation spatiale pour les performances
  • Interface responsive : Fenêtre entièrement modulaire en taille
  • Sauvegarde d'états : Système permettant de sauvegarder et restaurer l'état de la simulation
  • Gestion énergétique : Système de reproduction basé sur l'accumulation d'énergie
